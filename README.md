# Slide Tuner

Генерация и доработка содержания презентаций. `frontend` — React + TypeScript + Vite; `backend` — FastAPI; `docs` — API и развёртывание.

## Деплой одной командой

С Mac с настроенным Screenshot AI:

```bash
bash scripts/deploy-prod.sh
```

Скрипт использует его inventory и ключ, собирает backend на сервере, создаёт Slides env и токен, проверяет API снаружи и настраивает `frontend/.env`. См. [развёртывание](docs/deployment.md).

## Локальный фронт → production API

```bash
cd frontend
# После успешного deploy .env уже создан.
# Для ручной настройки: cp .env.example .env и заполнить токен.
npm ci
npm run dev
```

Открыть http://localhost:5173. Vite проксирует `/api` на `http://128.140.108.182:8280`. IP — целевой адрес sai-api-a; до развёртывания он не является подтверждённым работающим API. Токен читает только Vite, в JS-бандл он не попадает. Не используйте префикс VITE_ для секретов. Для другого сервера поменяйте `SLIDES_API_URL`.

## Возможности

1. Описание задачи + до 8 файлов PDF/DOCX/PPTX/TXT/MD/CSV, всего до 20 МБ. Сканы без текстового слоя пока не поддерживаются.
2. Макет с реальным текстом и редактированием заголовков/абзацев, четыре ползунка: подробность, сложность языка, тон, графики и диаграммы.
3. Область «Этот слайд / Вся презентация», фиксация точного текста, отмена последней генерации.
4. История проектов в localStorage: автосохранение, переименование, удаление, повторное открытие, скачивание резервной копии JSON. Сохраняются исходный извлечённый текст, слайды, настройки и ручные правки. Сами файлы не сохраняются; до первой генерации их нужно выбрать снова после перезагрузки. История доступна только в этом браузере и origin; очистка данных браузера удаляет её. Импорт резервной копии пока не реализован.

5. Девять ближайших вариантов настроек готовятся в фоне; готовый вариант применяется сразу. До 18 вариантов сохраняются вместе с проектом.
6. ИИ-чат в редакторе: вопросы и произвольные текстовые правки выбранного слайда или всей презентации. Агент получает исходники, текущие слайды, альтернативные тексты и историю диалога. Можно добавлять, удалять и переставлять слайды через чат всей презентации.

Служебные данные, контекст агента и предложение серверного хранения описаны в [схеме проекта](docs/project-storage.md).

Оформление, экспорт PPTX, чаты отдельных объектов и фон пока не входят в этот этап. Интерфейс показывает содержание до выбора темы.

## Локальный API

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements.txt
cp backend/.env.example backend/.env
# Заполнить ключи, затем загрузить переменные окружения:
set -a
. backend/.env
set +a
uvicorn app.main:app --app-dir backend --port 8280
```

Для локального API задайте во `frontend/.env` `SLIDES_API_URL=http://127.0.0.1:8280`.
