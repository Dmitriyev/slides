# Проверки первой версии

- `npm run build`: TypeScript + production-сборка Vite.
- `PYTHONPATH=backend pytest backend/tests -q`: загрузка, валидация, scope, неизменность ID, фиксация ручного текста, атомарность при ошибке модели, проверка чисел графика.
- `cd frontend && npm run test:history`: DOM-проверка черновика, автосохранения, повторного открытия после перезагрузки, ручного текста, фиксации, области rewrite и отсутствия дубликатов проектов.
- API-тесты используют замоканный ответ модели; реальные OpenRouter-запросы в этой среде не выполнялись — ключ отсутствует.
- Попытка браузерной проверки Chromium в среде разработки не выполнена: запуск браузера блокируется ограничением socket(). Скриншоты и визуальная проверка не подтверждены.
- Production deployment, firewall и внешний smoke-test не выполнены: SSH inventory и ключ отсутствуют.

- Deploy-тесты: выбор узлов и ключа, валидация inventory, сохранение токена, allowlist архива, конфигурация frontend, SSH/SCP-оркестрация и режим --check без изменений. Реальный сервер не использовался.
