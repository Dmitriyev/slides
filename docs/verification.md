# Проверки первой версии

- `npm run build`: TypeScript + production-сборка Vite.
- `cd backend && go test -race ./...`: загрузка, валидация, scope, неизменность ID, фиксация ручного текста, атомарность при ошибке модели, проверка чисел графика.
- `cd frontend && npm run test:history`: DOM-проверка черновика, автосохранения, повторного открытия после перезагрузки, ручного текста, фиксации, области rewrite и отсутствия дубликатов проектов.
- API-тесты используют замоканный ответ модели; реальные OpenRouter-запросы в этой среде не выполнялись — ключ отсутствует.
- Попытка браузерной проверки Chromium в среде разработки не выполнена: запуск браузера блокируется ограничением socket(). Скриншоты и визуальная проверка не подтверждены.
- Production deployment, firewall и внешний smoke-test не выполнены: SSH inventory и ключ отсутствуют.

- Deploy-тесты: выбор узлов и ключа, валидация inventory, сохранение токена, allowlist архива, конфигурация frontend, SSH/SCP-оркестрация и режим --check без изменений. Реальный сервер не использовался.

## Предзагрузка и чат

- Production-сборка TypeScript/Vite.
- API: контекст альтернатив и диалога; ответы без правок; область слайда; фиксация текста; добавление и перестановка слайдов; запрет удаления зафиксированных слайдов и дубликатов ID.
- DOM: девять готовых вариантов; мгновенное применение кэша; максимум два запроса одновременно; сохранение других слайдов; сброс кэша после ручной правки; отбрасывание запоздалых ответов; контекст чата; сохранение проекта при ошибке чата; история диалога после перезагрузки; миграция старых проектов.
- Проверки используют mock провайдера. Реальная скорость и качество новых ответов OpenRouter не измерены: ключа в этой рабочей среде нет.

## Перенос API на Go

- `cd backend && go test -race ./...` и `go vet ./...`: авторизация, CORS, лимиты запросов/файлов, multipart и form-urlencoded, валидация обязательных полей и типов, генерация, rewrite, chat, scope, locked-текст, атомарность ошибок, доказательства чисел графиков.
- PDF-тест использует реальный Poppler и проверяет текстовый слой, повреждённый файл и лимит 100 страниц. Без установленного Poppler этот тест пропускается; для полной проверки установите `poppler-utils` / `poppler`.
- DOCX/PPTX-тесты проверяют XML-текст, таблицу, несколько runs, XML entities и порядок слайдов через presentation relationships.
- OpenRouter проверяется локальным HTTP-сервером: заголовки, JSON schema, ответы и ошибки модели, три одновременных запроса, отмена запроса в очереди. Платный API не вызывается.
- `python3 -m pytest backend/tests/test_deploy.py -q`: скрипт деплоя и архив с Go-исходниками без секретов.
- Docker runtime и реальный production не проверялись: Docker, SSH inventory и ключ в среде отсутствуют. Тесты используют Go 1.24.13.
