# API v1

`GET /healthz` — статус процесса и наличие ключа генерации.
Все POST требуют `Authorization: Bearer <SLIDES_API_TOKEN>`. При работе локального фронта заголовок добавляет Vite proxy.

## POST /api/v1/presentations/generate

Multipart: `description` (до 20 000 символов), `files` (повторяемое поле), `slide_count` (1–20, default 6), `settings` (JSON).
Нужен хотя бы текст или один непустой документ. До 8 файлов, суммарно 20 МБ, извлечённый текст до 100 000 символов.

Settings: `{ "detail":1, "complexity":1, "tone":1, "charts":1 }`. Значения 0, 1, 2: низкий, средний, высокий уровень.

Ответ Deck: `{ title, source, slides:[{id,title,paragraphs,chart,note,locked,settings}] }`.
Chart: `{title,unit,data:[{label,value,evidence}]}` или null. Evidence — цитата из исходного текста. Сервер удаляет график при отсутствии точной цитаты/числа. Проверка не доказывает семантическую корректность выбора категорий моделью; все значения доступны для просмотра в ответе и в подсказках графика.

## POST /api/v1/presentations/rewrite

JSON: `{ "deck": <Deck>, "scope":"slide" | "deck", "slide_id":"...", "settings":<Settings> }`.
Статeless: актуальная версия проекта передаётся в каждом запросе. Возвращается полный Deck. Невыбранные слайды остаются без изменений. IDs сохраняются. При locked=true сервер сохраняет title и paragraphs дословно, даже если модель их изменила. Графики менять разрешено. Смешанная область не снимает фиксацию. Изменения возвращаются атомарно.

Ошибки: 401 — токен; 413 — объём; 415 — формат; 422 — параметры/нечитаемый файл; 502 — ошибка провайдера/невалидный результат; 503 — ключи не настроены. Запросы должны содержать Content-Length. HTTP таймаут провайдера — 110 секунд.

Файлы обрабатываются в памяти/временном multipart-файле; приложение не сохраняет проекты на сервер. Исходные материалы передаются провайдеру OpenRouter для генерации. История проектов находится в localStorage браузера.

## POST /api/v1/presentations/chat

JSON: `{ deck, scope, slide_id, settings, message, messages, alternatives }`.

- `message`: новый запрос, 1–20 000 символов.
- `messages`: до 20 прошлых `{role: "user" | "assistant", text}`.
- `alternatives`: до 18 `{key, scope, slide_id, settings, content: {title, slides}}`. Для slide в content только выбранный слайд. Source не дублируется.

Ответ: `{message, deck, changed}`. `changed=false` позволяет отвечать на вопросы без редактирования. Backend включает все альтернативные тексты в контекст агента. При правках выбранного слайда допускается ровно его исходный ID. Для deck разрешены добавление/удаление/перестановка; удаление зафиксированного слайда и дубли ID отклоняются с 502. Текст зафиксированных слайдов восстанавливается сервером, графики проверяются по source. Ошибка не возвращает частично изменённый deck.

Предзагрузка альтернатив использует существующий `/rewrite`: максимум два клиентских запроса одновременно, кэшируется до 18 результатов. [Схема хранения и правила ревизий](project-storage.md).
